## 🎨 Spesifikasi Teknis

### Format File
- **Primary:** `.webp` (modern, compressed)
- **Fallback:** `.jpg` (compatibility)
- **Quality:** 80-85% (balance between size & quality)

### Ukuran File
- **Max size per file:** 200KB (compressed)
- **Recommended:** 100-150KB

### Dimensi
- **Large cards:** 1200x800px (3:2)
- **Square cards:** 800x800px (1:1)
- **Hero images:** 1920x1080px (16:9)

### Style Guidelines
- ✅ Natural lighting (avoid harsh shadows)
- ✅ Clean & tidy environment
- ✅ Kids/students should look happy & engaged
- ✅ Show diversity (gender, age range)
- ✅ Bright colors but not oversaturated
- ✅ Focus on activity/action shots
- ✅ Avoid stock photo look (prefer authentic)

## 🔄 Cara Update Foto

### 1. Persiapkan Foto
- Resize ke dimensi yang tepat
- Convert ke WebP format (gunakan online converter atau Photoshop)
- Compress untuk web (tinypng.com atau squoosh.app)

### 2. Simpan ke Folder
```
public/images/education/
├── learning-animals.webp
├── learning-animals.jpg
├── urban-farming.webp
├── urban-farming.jpg
├── aero-glider.webp
├── aero-glider.jpg
├── profesor-cilik.webp
├── profesor-cilik.jpg
├── learning-batik.webp
├── learning-batik.jpg
├── traditional-dance.webp
├── traditional-dance.jpg
├── junior-masterchef.webp
├── junior-masterchef.jpg
└── ...
```

### 3. Update Controller (Jika Perlu)
File: `app/Http/Controllers/StaticPageController.php`
Line: 270-360

Contoh:
```php
[
    'title' => 'Aero Glider',
    'image' => asset('images/education/aero-glider.webp'),
    'imageFallback' => asset('images/education/aero-glider.jpg'),
    // ...
],
```

### 4. Clear Cache
```bash
php artisan cache:clear
php artisan view:clear
```

## 📸 Tips Foto Session

### Untuk Program Science
- Bawa props: lab coat, safety goggles, beaker, test tubes
- Setup experiment yang colorful (volcano, slime, color mixing)
- Capture ekspresi "aha moment"

### Untuk Program Art
- Gunakan kostum/props autentik (batik tools, chef hat, traditional costume)
- Tunjukkan proses (bukan hanya hasil akhir)
- Include instruktur dalam beberapa shots

### Untuk Program Environment
- Golden hour lighting (pagi atau sore)
- Banyak greenery di background
- Action shots (tidak statis/pose)

## 🌟 Referensi Gaya Foto

**Style yang Diinginkan:**
- 📸 Documentary style (candid, natural)
- 🎨 Bright & cheerful color palette
- 👥 Focus on kids' expressions & engagement
- 🌿 Show the Godong Ijo environment

**Hindari:**
- ❌ Overly posed/stiff
- ❌ Too dark/underexposed
- ❌ Cluttered background
- ❌ Generic stock photo vibe
